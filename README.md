**📊 Sales Performance Dashboard (Power BI)**

**📘 Project Overview**

This project involves developing a Power BI Sales Performance Dashboard to analyze revenue trends, product category performance, regional sales contribution, and sales team efficiency. The dashboard provides dynamic and interactive insights that support strategic decision-making and performance optimization.

The data was collected, cleaned, modeled, and visualized within Power BI using Power Query, DAX, and data relationships to create an analytical model suitable for business reporting.

**🚀 Key Features**

**Interactive Visual Dashboard:**
Visualized key sales metrics such as Total Revenue, Profit, Average Discount, and Order Volume.

**Product & Region Performance:**
Compared sales performance across product categories, regions, and time periods.

**Trend & KPI Tracking:**
Analyzed monthly and quarterly trends to identify growth opportunities and seasonal patterns.

**Drill-Down Insights:**
Used slicers and drill-down charts to filter performance by location, product segment, and date.

**🧠 Skills Used**
Power Query	Data cleaning & transformation
DAX (Data Analysis Expressions)	Creating measures, calculated fields, KPI metrics
Data Modeling	Building relationships for accurate filtering and aggregation
Visualization Design	Creating dashboards and drill-down visual reports

**⚙️ How It Works**

Raw sales data is imported into Power BI.

Power Query is used to clean and restructure the dataset.

Data relationships are created between fact and dimension tables.

DAX measures are built to calculate KPIs such as revenue, profit, and order count.

Dashboards are designed with visuals like column charts, line graphs, KPIs, maps, and slicers.

**📊 Dashboard Insights**

**Sales Trends:** Identifies high-performing months and slow periods.

**Category Performance:** Highlights top-selling and low-selling product categories.

**Regional Revenue:** Shows which regions contribute the most to sales volume.

**Discount Impact:** Understands how discount rates influence revenue and profit margins.
